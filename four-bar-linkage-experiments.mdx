## The four-bar linkage in brief

A four-bar linkage is four rigid bars joined in a loop by four pin joints. One bar is the frame of the machine and does not move: the ground. A motor turns the bar next to it, the crank. A third bar, the coupler, carries the motion across to the last bar, the follower, which is the output.

You have seen one in a car wiper (the motor turns fully and the wiper arm swings), in an oil well pump jack, in a bus door and in a folding chair.

```text
                     coupler b
          A o--------------------------o B
           /                            \
  crank a /                              \ follower c
         /                                \ (output)
     O2 o----------------------------------o O4
      motor          ground d          output pivot
```

The experiments answer three questions that a designer must settle before cutting metal. Can the motor turn the crank all the way round? How well does the coupler push the follower at each position? How much may the lengths vary before the answers change?

## Key Terms

| Term | Meaning |
|------|---------|
| **$a$** | Crank length (mm): the bar that the motor turns |
| **$b$** | Coupler length (mm): the bar that joins the crank (at joint A) to the follower (at joint B). Neither end is fixed to the frame |
| **$c$** | Follower length (mm): the output bar, also called the rocker when it only swings |
| **$d$**, **$e$** | Ground: the horizontal distance $d$ and the vertical offset $e$ (mm) between the two fixed pivots $O_2$ and $O_4$ |
| **$\theta_2$, $\theta_3$, $\theta_4$** | Angles of the crank, the coupler and the follower (degrees), measured from the horizontal |
| **$\omega$, $\alpha$** | Angular velocity ($\text{rad/s}$) and angular acceleration ($\text{rad/s}^2$) of a bar. The number names the bar, so $\omega_4$ and $\alpha_4$ belong to the follower |
| **Grashof** | Add the shortest length $s$ and the longest length $l$. If $s + l \le p + q$, where $p$ and $q$ are the other two lengths, at least one bar can turn fully. If not, every bar only rocks |
| **Crank-rocker** | Grashof linkage where the shortest bar is the crank: it turns fully while the follower swings |
| **Double-crank** | Grashof linkage where the shortest bar is the ground: both crank and follower turn fully |
| **Double-rocker** | Either non-Grashof (no full rotation) or Grashof with the coupler as the shortest bar |
| **Transmission angle $\mu$** | The angle between the coupler and the follower at joint B, taken between $0^\circ$ and $90^\circ$. Near $90^\circ$ the coupler pushes across the follower and turns it well. Below about $40^\circ$ most of the push only loads the bearings |
| **Coupler curve** | The path traced by a point on the coupler as the mechanism moves |
| **Circuit** | The two ways to assemble the same four bars: open and crossed. They are mirror images about the line from A to $O_4$. In the simulator, open puts joint B on the left of that line as you look from A toward $O_4$ |

## Experiment 1: The Grashof Condition

<InArticleAd />


A motor turns in one direction without stopping. If the bar it drives cannot go all the way round, the motor stalls against the linkage and something bends or burns. So the first check on any four-bar is whether the driven bar can make a full turn.

The Grashof condition answers this from the lengths alone. If the shortest length plus the longest, $s + l$, is smaller than the sum of the other two, $p + q$, the shortest bar can turn fully (Grashof). If it is larger, no bar can (non-Grashof). You will build four linkages on and near that boundary, predict each one, and check it.

:::note[Objective]
Verify the Grashof condition experimentally by building linkages at and near the Grashof boundary, and observe how the mechanism behavior changes.
:::

<Steps>
1. **Crank-rocker (Grashof)**
   Set $a=40$, $b=120$, $c=80$, $d=100$. Predict: $s+l = 40+120 = 160$, $p+q = 80+100 = 180$. Grashof: yes. Run the experiment and start the animation. The crank should complete full rotations.

2. **Make it non-Grashof**
   Change $a=80$ (so now $s=80$, $l=120$, and $s+l=200$ is greater than $p+q=180$). Run the experiment. Start the animation. Near $\theta_2 = 0$ the drawing is replaced by the message "Invalid configuration", and the charts sit flat at zero: there joint A is so close to $O_4$ that the coupler and the follower cannot meet.

3. **Boundary case**
   Set $a=60$, $b=120$, $c=80$, $d=100$. Now $s+l = 60+120 = 180 = p+q$. This is a change-point mechanism. Run it and look at $\theta_2 = 0$: all four bars lie along the ground line, the transmission angle reads $0^\circ$, and from there the follower is free to leave in either direction. A real machine can jump to the other assembly at this point.

4. **Double-crank**
   Select the Double-Crank preset ($a=60$, $b=80$, $c=70$, $d=40$). The shortest bar is now the ground, and both the crank and the follower turn fully.

5. **Record Grashof status**
   For each of the four configurations, record $s+l$, $p+q$, the Grashof type shown in the simulator, whether the crank completes a full rotation, and the minimum transmission angle. Save as `data/exp1_grashof.csv`.
</Steps>

### Python Analysis

```python title="experiment_1_grashof.py"
import numpy as np
import matplotlib.pyplot as plt
import csv
import os

# ============================================================
# STEP 1: Load your CSV data from the simulator
# Place your downloaded CSV in the data/ folder, or update the path
# ============================================================
csv_file = 'data/exp1_baseline.csv'
sim_data = None

if os.path.exists(csv_file):
    with open(csv_file) as f:
        reader = csv.DictReader(f)
        sim_data = list(reader)
    print(f"Loaded {len(sim_data)} rows from {csv_file}")
else:
    print(f"No CSV found at {csv_file}. Using analytical data only.")
    print("To use simulator data: download CSV from the simulator or")
    print("record values from the charts into a CSV with these columns:")
    print("Input Angle (deg), Coupler Angle (deg), Follower Angle (deg), ...")

# ============================================================
# STEP 2: Analytical computation (for comparison)
# ============================================================
def solve_fourbar(a, b, c, d, e, theta2_deg):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:
        return None
    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2
    if hsq < 0: return None
    h = np.sqrt(hsq)
    mx, my = Ax + ca*dx/dist, Ay + ca*dy/dist
    Bx, By = mx - h*dy/dist, my + h*dx/dist  # open circuit, as in the simulator
    t3 = np.degrees(np.arctan2(By-Ay, Bx-Ax))
    t4 = np.degrees(np.arctan2(By-e, Bx-d))
    return {'theta3': t3, 'theta4': t4}

# Test Grashof condition for multiple configurations
configs = [
    {'a': 40, 'b': 120, 'c': 80, 'd': 100, 'e': 0, 'name': 'Crank-rocker'},
    {'a': 80, 'b': 120, 'c': 80, 'd': 100, 'e': 0, 'name': 'Non-Grashof'},
    {'a': 60, 'b': 120, 'c': 80, 'd': 100, 'e': 0, 'name': 'Change-point'},
    {'a': 60, 'b': 80, 'c': 70, 'd': 40, 'e': 0, 'name': 'Double-crank'},
]

print("\nGrashof Classification:")
for cfg in configs:
    D = np.sqrt(cfg['d']**2 + cfg['e']**2)
    links = sorted([cfg['a'], cfg['b'], cfg['c'], D])
    s, l = links[0], links[3]
    grashof = 'Grashof' if s + l <= links[1] + links[2] else 'Non-Grashof'
    if abs(s + l - links[1] - links[2]) < 0.01: grashof = 'Change-point'
    valid = sum(1 for t in range(361) if solve_fourbar(cfg['a'],cfg['b'],cfg['c'],cfg['d'],cfg['e'],t))
    print(f"  {cfg['name']}: s+l={s+l:.0f}, p+q={links[1]+links[2]:.0f} -> {grashof}, valid={valid}/361")

# ============================================================
# STEP 3: If CSV loaded, plot simulator data vs analytical
# ============================================================
if sim_data:
    sim_angles = [float(r['Input Angle (deg)']) for r in sim_data]
    sim_theta3 = [float(r['Coupler Angle (deg)']) for r in sim_data]
    sim_theta4 = [float(r['Follower Angle (deg)']) for r in sim_data]

    # Compute analytical for baseline config
    a, b, c, d, e = 40, 120, 80, 100, 0
    anal_theta3, anal_theta4 = [], []
    for t in sim_angles:
        r = solve_fourbar(a, b, c, d, e, t)
        anal_theta3.append(r['theta3'] if r else np.nan)
        anal_theta4.append(r['theta4'] if r else np.nan)

    fig, axes = plt.subplots(2, 1, figsize=(10, 8), sharex=True)
    axes[0].plot(sim_angles, sim_theta3, 'b-', label='Simulator', linewidth=2)
    axes[0].plot(sim_angles, anal_theta3, 'r--', label='Analytical', linewidth=1)
    axes[0].set_ylabel('Coupler Angle (deg)')
    axes[0].legend()
    axes[0].set_title('Experiment 1: Simulator vs Analytical Comparison')

    axes[1].plot(sim_angles, sim_theta4, 'b-', label='Simulator', linewidth=2)
    axes[1].plot(sim_angles, anal_theta4, 'r--', label='Analytical', linewidth=1)
    axes[1].set_ylabel('Follower Angle (deg)')
    axes[1].set_xlabel('Input Angle (deg)')
    axes[1].legend()

    plt.tight_layout()
    plt.savefig('plots/experiment_1_comparison.png', dpi=150)
    plt.show()

    # Compute error
    errors = [abs(s - a) for s, a in zip(sim_theta4, anal_theta4) if not np.isnan(a)]
    print(f"\nFollower angle: max error = {max(errors):.4f} deg, mean error = {np.mean(errors):.4f} deg")
```

### Expected Results

- $a=40$, $b=120$, $c=80$, $d=100$: Grashof ($s+l=160 < p+q=180$), crank completes full rotation
- $a=80$, $b=120$, $c=80$, $d=100$: Non-Grashof ($s+l=200 > p+q=180$), crank locks within about $22.3^\circ$ of $\theta_2 = 0$, so 315 of the 361 positions are valid
- $a=60$, $b=120$, $c=80$, $d=100$: Change-point ($s+l=180 = p+q$), mechanism reaches singular positions
- $a=60$, $b=80$, $c=70$, $d=40$: Grashof double-crank ($s+l=120 < p+q=130$, shortest link is ground). This is the simulator's double-crank preset

### Design Question

You need a mechanism where the input crank makes full rotations but the output oscillates. Which link must be the shortest? What happens if manufacturing errors make one link $2\,\text{mm}$ longer than specified, pushing $s+l$ past the boundary?

## Experiment 2: Transmission Angle and Mechanism Quality

<InArticleAd />


A linkage can pass the Grashof test and still stall under load. The coupler can only push along its own length, and only the part of that push that acts across the follower turns it: the push multiplied by $\sin\mu$, where $\mu$ is the transmission angle.

At $\mu = 90^\circ$ all of the push turns the follower. At $40^\circ$ it is 64%. At $26^\circ$ it is 44%, and the rest only presses on the bearings, where friction can hold the linkage still. So designers try to keep $\mu$ above about $40^\circ$ over the whole turn. This experiment finds where $\mu$ is smallest and how the lengths control it.

:::note[Objective]
Map how transmission angle varies through the cycle for different link ratios, and identify configurations where the minimum transmission angle drops below the $40^\circ$ practical limit.
:::

<Steps>
1. **Baseline transmission angle**
   Use the crank-rocker preset ($a=40$, $b=120$, $c=80$, $d=100$). Run the experiment. Open the Transmission Angle tab. Note Min $\mu$ and Max $\mu$ from the summary panel, and the crank angle at which the curve is lowest.

2. **Save as Experiment A**

3. **Degrade the transmission angle**
   Change $c=40$ (shorter follower). Run the experiment. The transmission angle should dip lower. This linkage is no longer Grashof ($s+l=160 > p+q=140$), so the crank also locks over part of the turn.

4. **Improve the transmission angle**
   Clear Experiment A. Set $a=30$, $b=100$, $c=90$, $d=100$. Run the experiment. Check whether the whole curve now stays above $40^\circ$.

5. **Collect data**
   For each configuration, record min and max transmission angle. Save as `data/exp2_transmission.csv`.
</Steps>

### Python Analysis

```python title="experiment_2_transmission.py"
import numpy as np
import matplotlib.pyplot as plt
import csv
import os

# ============================================================
# STEP 1: Load CSV data from the simulator
# Download CSV from the simulator or record from charts
# ============================================================
csv_files = {
    'Baseline': 'data/exp2_baseline.csv',
    'Short follower': 'data/exp2_short_follower.csv',
    'Improved': 'data/exp2_improved.csv',
}
sim_datasets = {}
for label, path in csv_files.items():
    if os.path.exists(path):
        with open(path) as f:
            sim_datasets[label] = list(csv.DictReader(f))
        print(f"Loaded {len(sim_datasets[label])} rows from {path}")
    else:
        print(f"No CSV at {path} (will use analytical only for {label})")

# ============================================================
# STEP 2: Analytical computation (two-circle intersection)
# ============================================================
def solve_fourbar(a, b, c, d, e, theta2_deg):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:
        return None
    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2
    if hsq < 0: return None
    h = np.sqrt(hsq)
    mx, my = Ax + ca*dx/dist, Ay + ca*dy/dist
    Bx, By = mx - h*dy/dist, my + h*dx/dist  # open circuit, as in the simulator
    t3 = np.degrees(np.arctan2(By-Ay, Bx-Ax))
    t4 = np.degrees(np.arctan2(By-e, Bx-d))
    mu = abs(t3 - t4)
    if mu > 180: mu = 360 - mu
    if mu > 90: mu = 180 - mu
    return {'theta3': t3, 'theta4': t4, 'mu': mu}

configs = [
    {'a': 40, 'b': 120, 'c': 80, 'd': 100, 'e': 0, 'label': 'Baseline'},
    {'a': 40, 'b': 120, 'c': 40, 'd': 100, 'e': 0, 'label': 'Short follower'},
    {'a': 30, 'b': 100, 'c': 90, 'd': 100, 'e': 0, 'label': 'Improved'},
]

theta2 = np.arange(0, 361)
fig, ax = plt.subplots(figsize=(10, 5))

# ============================================================
# STEP 3: Plot simulator data vs analytical
# ============================================================
for cfg in configs:
    # Analytical
    mu_anal = []
    for t in theta2:
        r = solve_fourbar(cfg['a'], cfg['b'], cfg['c'], cfg['d'], cfg['e'], t)
        mu_anal.append(r['mu'] if r else np.nan)
    mu_anal = np.array(mu_anal)

    label = cfg['label']
    if label in sim_datasets:
        sim = sim_datasets[label]
        sim_angles = [float(row['Input Angle (deg)']) for row in sim]
        sim_mu = [float(row['Transmission Angle (deg)']) for row in sim]
        ax.plot(sim_angles, sim_mu, '-', label=f'{label} (simulator)', linewidth=2)
        ax.plot(theta2, mu_anal, '--', label=f'{label} (analytical)', linewidth=1, alpha=0.7)
        # Error
        common = min(len(sim_mu), len(mu_anal))
        errors = [abs(s - a) for s, a in zip(sim_mu[:common], mu_anal[:common]) if not np.isnan(a)]
        if errors:
            print(f"{label}: max error = {max(errors):.4f} deg, mean = {np.mean(errors):.4f} deg")
    else:
        ax.plot(theta2, mu_anal, '-', label=label, linewidth=2)

    valid = mu_anal[~np.isnan(mu_anal)]
    print(f"{label}: min mu = {np.nanmin(mu_anal):.1f}, max mu = {np.nanmax(mu_anal):.1f}")

ax.axhline(y=40, color='r', linestyle='--', alpha=0.5, label='40 deg limit')
ax.set_xlabel('Input Angle (degrees)')
ax.set_ylabel('Transmission Angle (degrees)')
ax.set_title('Experiment 2: Transmission Angle Comparison')
ax.legend(fontsize=8)
plt.tight_layout()
plt.savefig('plots/experiment_2_transmission.png', dpi=150)
plt.show()
```

### Expected Results

- Baseline ($a=40$, $b=120$, $c=80$, $d=100$): transmission angle runs from $26.4^\circ$ (at $\theta_2 = 0$) to $86.4^\circ$ (at $\theta_2 = 180^\circ$), so it drops below the $40^\circ$ limit even though the linkage is Grashof
- Short follower ($c=40$): the linkage is non-Grashof ($s+l=160 > p+q=140$). The crank cannot pass within about $49.5^\circ$ of $\theta_2 = 0$, and the transmission angle falls toward $0^\circ$ at those limits (the script reports $6.3^\circ$ on its $1^\circ$ grid)
- Improved ($a=30$, $b=100$, $c=90$, $d=100$): transmission angle runs from $42.8^\circ$ to $86.2^\circ$, above the $40^\circ$ limit through the whole cycle

```python title="experiment_3_presets.py"
import numpy as np
import matplotlib.pyplot as plt
import csv
import os

# ============================================================
# STEP 1: Load CSV data from the simulator for each preset
# Download CSV from the simulator for each preset configuration
# ============================================================
csv_files = {
    'Crank-Rocker': 'data/exp3_crank_rocker.csv',
    'Double-Crank': 'data/exp3_double_crank.csv',
    'Double-Rocker': 'data/exp3_double_rocker.csv',

for name, path in csv_files.items():

        with open(path) as f:
            sim_datasets[name] = list(csv.DictReader(f))
        print(f"Loaded {len(sim_datasets[name])} rows for {name}")
    else:
        print(f"No CSV at {path} (analytical only for {name})")

# ============================================================
# STEP 2: Analytical computation (two-circle intersection)
# ============================================================
def solve_fourbar(a, b, c, d, e, theta2_deg):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:
        return None
    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2
    if hsq < 0: return None
    h = np.sqrt(hsq)
    mx, my = Ax + ca*dx/dist, Ay + ca*dy/dist
    Bx, By = mx - h*dy/dist, my + h*dx/dist  # open circuit, as in the simulator
```

```python title="experiment_4_circuits.py"
# STEP 2: Analytical computation (two-circle intersection)
# Open circuit: B above the line A-O4

def solve_fourbar_circuit(a, b, c, d, e, theta2_deg, circuit='open'):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:

    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2

    sign = -1 if circuit == 'open' else 1

    By = my - sign * h * dx / dist

    t3 = np.degrees(np.arctan2(By - Ay, Bx - Ax))
    mu = abs(t3 - t4)
    if mu > 180: mu = 360 - mu
    if mu > 90: mu = 180 - mu
    return {'theta4': t4, 'mu': mu}
```

## Experiment 7: Angular Acceleration and Inertia Forces

<InArticleAd />


A linkage that runs quietly at $60\,\text{RPM}$ can break its bearings at $300\,\text{RPM}$ with the same geometry. The cause is angular acceleration, $\alpha$: how fast the angular velocity of a bar changes. To change the speed of a bar, the joints must apply a torque equal to its moment of inertia multiplied by $\alpha$, so a large $\alpha$ means large joint forces, vibration and noise. This experiment finds where $\alpha$ is largest and how it grows with speed.

:::note[Objective]
Map the angular acceleration profiles of the coupler and follower, identify the peak values, and understand how they relate to inertia forces in the mechanism.
:::

<Steps>

### Python Analysis

```python title="experiment_7_acceleration.py"
import numpy as np
import matplotlib.pyplot as plt
import csv
import os

# ============================================================
# STEP 1: Load CSV data from the simulator
# Run at 60 RPM and 120 RPM, download CSV for each
# ============================================================
csv_files = {
    '60 RPM': 'data/exp7_60rpm.csv',
    '120 RPM': 'data/exp7_120rpm.csv',
}
sim_datasets = {}
for label, path in csv_files.items():
    if os.path.exists(path):
        with open(path) as f:
            sim_datasets[label] = list(csv.DictReader(f))
        print(f"Loaded {len(sim_datasets[label])} rows for {label}")
    else:
        print(f"No CSV at {path} (analytical only for {label})")

# ============================================================
# STEP 2: Analytical computation (two-circle intersection + velocity)
# ============================================================
def solve_fourbar_vel(a, b, c, d, e, theta2_deg, omega2):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:
        return None
    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2
    if hsq < 0: return None
    h = np.sqrt(hsq)
    mx, my = Ax + ca*dx/dist, Ay + ca*dy/dist
    # Open circuit, the same branch the simulator assembles under "Open".
    # Flipping these two signs gives the crossed circuit.
    Bx, By = mx - h*dy/dist, my + h*dx/dist
    t3 = np.arctan2(By-Ay, Bx-Ax)
    t4 = np.arctan2(By-e, Bx-d)
    sin34 = np.sin(t3 - t4)
    if abs(sin34) < 1e-10: return None
    # Note the denominators differ by a sign: omega3 divides by sin(t3-t4),
    # omega4 by sin(t4-t3).
    w3 = a*omega2*np.sin(t4 - t2) / (b*sin34)
    w4 = a*omega2*np.sin(t2 - t3) / (c*np.sin(t4 - t3))

    # Angular accelerations, for a constant-speed input (alpha2 = 0). Solving
    # the twice-differentiated loop as a 2x2 system in alpha3 and alpha4.
    AA = c*np.sin(t4); BB = b*np.sin(t3)
    DD = c*np.cos(t4); EE = b*np.cos(t3)
    CC = a*omega2**2*np.cos(t2) + b*w3**2*np.cos(t3) - c*w4**2*np.cos(t4)
    FF = -a*omega2**2*np.sin(t2) - b*w3**2*np.sin(t3) + c*w4**2*np.sin(t4)
    den = AA*EE - BB*DD
    if abs(den) < 1e-10: return None
    a3 = (CC*DD - AA*FF) / den
    a4 = (CC*EE - BB*FF) / den
    return {'omega3': w3, 'omega4': w4, 'alpha3': a3, 'alpha4': a4}

a, b, c, d, e_off = 40, 120, 80, 100, 0
theta2 = np.arange(0, 361)

# ============================================================
# STEP 3: Plot simulator data vs analytical
# ============================================================
fig, axes = plt.subplots(2, 1, figsize=(10, 8), sharex=True)
rpm_colors = {'60 RPM': 'blue', '120 RPM': 'red'}

for rpm, color, label in [(60, 'blue', '60 RPM'), (120, 'red', '120 RPM')]:
    omega2 = rpm * 2 * np.pi / 60
    # Analytical
    a4_anal, a3_anal = [], []
    for t in theta2:
        r = solve_fourbar_vel(a, b, c, d, e_off, t, omega2)
        a4_anal.append(r['alpha4'] if r else np.nan)
        a3_anal.append(r['alpha3'] if r else np.nan)
    a4_anal = np.array(a4_anal)
    a3_anal = np.array(a3_anal)

    if label in sim_datasets:
        sim = sim_datasets[label]
        sim_angles = [float(row['Input Angle (deg)']) for row in sim]
        sim_a4 = [float(row['Alpha4 (rad/s2)']) for row in sim]
        sim_a3 = [float(row['Alpha3 (rad/s2)']) for row in sim]
        axes[0].plot(sim_angles, sim_a4, '-', color=color,
                     label=f'{label} (simulator)', linewidth=2)
        axes[0].plot(theta2, a4_anal, '--', color=color,
                     label=f'{label} (analytical)', linewidth=1, alpha=0.6)
        axes[1].plot(sim_angles, sim_a3, '-', color=color,
                     label=f'{label} (simulator)', linewidth=2)
        axes[1].plot(theta2, a3_anal, '--', color=color,
                     label=f'{label} (analytical)', linewidth=1, alpha=0.6)
        # Error report
        common = min(len(sim_a4), len(a4_anal))
        errs = [abs(s - a) for s, a in zip(sim_a4[:common], a4_anal[:common]) if not np.isnan(a)]
        if errs:
            print(f"{label}: alpha4 max error = {max(errs):.4f} rad/s2")
    else:
        axes[0].plot(theta2, a4_anal, '-', color=color, label=label, linewidth=2)
        axes[1].plot(theta2, a3_anal, '-', color=color, label=label, linewidth=2)

    peak = np.nanmax(np.abs(a4_anal))
    where = theta2[int(np.nanargmax(np.abs(a4_anal)))]
    print(f"{label}: peak |alpha4| = {peak:.2f} rad/s2 at theta2 = {where} deg")

axes[0].set_ylabel('Follower alpha4 (rad/s2)')
axes[0].set_title('Experiment 7: Angular Acceleration at Different Speeds')
axes[0].legend(fontsize=8)
axes[0].axhline(y=0, color='k', linewidth=0.5)
axes[1].set_ylabel('Coupler alpha3 (rad/s2)')
axes[1].set_xlabel('Input Angle (degrees)')
axes[1].legend(fontsize=8)
axes[1].axhline(y=0, color='k', linewidth=0.5)

plt.tight_layout()
plt.savefig('plots/experiment_7_acceleration.png', dpi=150)
plt.show()

print(f"\nSpeed ratio: 2x -> omega4 ratio 2x (linear), alpha ratio 4x (quadratic)")
print(f"Acceleration ratio should be 4x (quadratic)")
```

## Experiment 8: Breaking the Mechanism

<InArticleAd />


A bar cut a few millimeters too long can make a working linkage jam, and only at some crank angles, so a quick test by hand may miss it. The loop can close only when the distance from joint A to pivot $O_4$ is no more than $b + c$ and no less than the difference between $b$ and $c$. Outside those limits the coupler and the follower cannot meet. This experiment maps the crank angles where that happens.

:::note[Objective]
Find the geometric constraints that determine whether a four-bar linkage can assemble, and observe partial-rotation failure modes.
:::

<Steps>
1. **Working mechanism**
   Set $a=40$, $b=120$, $c=80$, $d=100$. Run the experiment. All 361 data points should be valid.

2. **Increase the crank**
   Change $a=90$. The sum $s+l$ now exceeds $p+q$. Start the animation. At what angles does the message "Invalid configuration" appear?

3. **Extreme case**
   Set $a=120$, $b=40$, $c=80$, $d=100$. The "crank" is now longer than the coupler. Try to animate.

4. **Triangle inequality**
   Set $a=20$, $b=30$, $c=30$, $d=100$. No valid assembly exists at any angle because the links cannot form a closed chain: the longest link ($100$) is longer than the other three together ($20+30+30=80$).

5. **Collect data**
   For each configuration, record $s+l$, $p+q$ and the angles where the mechanism fails. The script below counts the valid positions out of 361 (one for each degree from $0$ to $360$). Save as `data/exp8_breaking.csv`.
</Steps>

## Experiment 9: Ground Offset and Effective Ground Length

<InArticleAd />


Textbook four-bars have both fixed pivots on a horizontal line. Real machines often cannot: a motor mount sits above the frame, or a pivot is moved to clear a bearing housing. Then one pivot is higher than the other by an offset $e$, and a design that was checked for $e = 0$ may no longer behave as planned.

The distance between the pivots is the long side of a right triangle with sides $d$ and $e$, so the effective ground length grows from $d$ to $\sqrt{d^2 + e^2}$. That changes the Grashof sums, the transmission angle and the coupler curve. The ground offset slider of the simulator lets you see by how much.

:::note[Objective]
Quantify how vertical ground offset changes the effective ground length, Grashof classification, follower oscillation, and transmission angle quality for the same set of link lengths.
:::

<Steps>
1. **Baseline with zero offset**
   Set $a=40$, $b=120$, $c=80$, $d=100$, $e=0$. Run the experiment. Record the Grashof type, follower oscillation range, and min transmission angle.

2. **Small offset**
   Set $e=20$. The effective ground length is now $\sqrt{100^2 + 20^2} = 101.98\,\text{mm}$. The mechanism is still Grashof, but the follower oscillation and transmission angle have shifted. Run and record.

3. **Moderate offset**
   Set $e=40$. Effective ground $= \sqrt{100^2 + 40^2} = 107.7\,\text{mm}$. Run and record. Does the Grashof type change?

4. **Critical offset**
   Set $e=50$. Effective ground $= \sqrt{100^2 + 50^2} = 111.8\,\text{mm}$. Now $s+l = 40+120 = 160$, and $p+q = 80+111.8 = 191.8$. Still Grashof, and the margin has grown from $20$ to $31.8\,\text{mm}$. Compare with $e=0$.

5. **Large offset (classification flip)**
   The offset slider stops at $e=50$, and the linkage is still a crank-rocker there. The classification flips only when $s+l = 40 + D$ passes $p+q = 120+80 = 200$, at $D = 160\,\text{mm}$ or $e = \sqrt{160^2 - 100^2} = 124.9\,\text{mm}$. Use the Python script below to confirm it.

6. **Negative offset**
   Run $e=+30$ and save it as Experiment A. Then set $e=-30$ and run. The effective ground length is the same ($104.4\,\text{mm}$), but the ground line now tilts down by $16.7^\circ$ instead of up. On the Follower $\theta_4$ chart, decide whether the two curves are identical, mirrored or shifted.

7. **Collect data**
   For each offset value, record the effective ground $D$, Grashof type, follower oscillation, and min transmission angle. The script prints the valid positions. Save as `data/exp9_offset.csv`.
</Steps>

```python title="experiment_9_ground_offset.py"
import matplotlib.pyplot as plt
import csv
import os

# ============================================================

        with open(path) as f:
            sim_datasets[e_val] = list(csv.DictReader(f))
        print(f"Loaded {len(sim_datasets[e_val])} rows for e={e_val}")
    else:

# ============================================================
# STEP 2: Analytical computation (two-circle intersection)

def solve_fourbar(a, b, c, d, e, theta2_deg):
    t2 = np.radians(theta2_deg)
    Ax, Ay = a*np.cos(t2), a*np.sin(t2)
    dx, dy = d - Ax, e - Ay
    dist = np.sqrt(dx**2 + dy**2)
    if dist > b+c or dist < abs(b-c) or dist < 1e-10:
        return None
    ca = (b**2 - c**2 + dist**2) / (2*dist)
    hsq = b**2 - ca**2
    if hsq < 0: return None
    h = np.sqrt(hsq)
    mx, my = Ax + ca*dx/dist, Ay + ca*dy/dist
    Bx, By = mx - h*dy/dist, my + h*dx/dist  # open circuit, as in the simulator
```

### Expected Results

- At $e=0$, the crank-rocker works at all 361 positions with a Grashof margin of $20\,\text{mm}$
- As offset increases, the effective ground $D$ grows. While $D$ is below $120\,\text{mm}$ the coupler is still the longest link, so the margin $p+q-s-l = D - 80$ grows too: $22.0\,\text{mm}$ at $e=20$, $27.7\,\text{mm}$ at $e=40$ and $31.8\,\text{mm}$ at $e=50$
- The margin peaks at $40\,\text{mm}$ when $D = 120\,\text{mm}$ ($e = 66.3\,\text{mm}$). Beyond that the ground is the longest link and the margin falls as $160 - D$. The Grashof boundary ($s+l = p+q$) is crossed at $D = 160\,\text{mm}$, which is $e = 124.9\,\text{mm}$ for $a=40$, $b=120$, $c=80$, $d=100$. The slider range ($\pm 50\,\text{mm}$) never reaches it, so the simulator shows a crank-rocker with 361 valid positions at every offset
- Follower oscillation narrows with offset: $73.8^\circ$ at $e=0$, $72.2^\circ$ at $e=20$, $68.5^\circ$ at $e=40$ and $66.3^\circ$ at $e=50$
- The transmission angle minimum improves with offset: $26.4^\circ$ at $e=0$, $28.0^\circ$ at $e=20$, $32.4^\circ$ at $e=40$ and $35.4^\circ$ at $e=50$. It stays below $40^\circ$ over the whole slider range
- Offsets of $+30$ and $-30$ give the same effective ground length, oscillation and minimum transmission angle. The follower angle curve keeps its shape but is shifted, not mirrored: $\theta_4$ runs from $76.9^\circ$ to $147.4^\circ$ at $e=+30$ and from $43.5^\circ$ to $114.0^\circ$ at $e=-30$, a shift of $33.4^\circ$ (twice the ground tilt of $16.7^\circ$), with the same shift along the input angle axis
